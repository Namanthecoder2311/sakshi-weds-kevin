# Paintings for the invitation: prompts for ChatGPT or Gemini

Paste each prompt into **ChatGPT (image generation)** or **Gemini**, then download the result
and save it in this project's **`public/art/`** folder with exactly the file name shown.
The site picks each painting up automatically. Until a file is there, a simple stand-in appears in its place.

Tips
- Generate 2–3 versions of each one and keep the one you like best.
- If the tool adds any text or a signature, ask it to "remove all text and the signature".
- JPG or PNG both work, but the file name must match exactly (for example `cover.jpg`).
  If you save a PNG, rename it to `.jpg` or tell me and I'll update the code.
